3D 个人照片墙｜简洁版（含背景音乐）

使用：
1. 解压后打开 index.html。默认在线示例照片需要联网。
2. 把个人照片放进 photos 文件夹，命名为 photo-01.jpg、photo-02.jpg……。
3. 打开 index.html，搜索 getImages()，将 return demoPhotos; 改为 return photos; 即可使用本地照片。
4. 在 const photos 数组里添加/删除照片路径，数量不限。
5. 把你有权使用的 MP3 音乐文件放进 music 文件夹，并命名为 background.mp3。
6. 点击网页右上方「♫ 音乐 · 关」即可播放或暂停背景音乐。默认音量 35%，循环播放。
   浏览器通常不允许网页未经用户操作自动播放声音，因此需要点击音乐按钮。
7. 鼠标或手指拖动照片墙即可自定义旋转方向；支持自动旋转开关、速度调节、复位和点击放大。
8. 纯前端静态页面，无需安装依赖或启动后端。
\n照片墙布局已调整：照片环横向和纵向分布更开，尽量利用屏幕空间；可拖动旋转查看各个角度。\n
布局更新：照片主要沿水平方向分散，纵向起伏已压低，整体更接近横向环形照片墙。

重叠优化：照片分布使用更宽、更浅的椭圆环；照片本身保持正面朝向，减小旋转时相互遮挡的情况。

圆柱体布局：照片均匀分布在竖直圆柱外壁，照片沿圆周转动并随角度改变朝向；支持拖动旋转、自动旋转和速度控制。

本版本调整：照片沿圆柱分布得更分散，并在旋转到左右边缘时逐渐变透明，正面照片保持清晰。


清晰度优化版：已增大照片墙卡片尺寸、优化 3D 透视，并放大点击后的原图预览区域。建议使用原始高清照片，不要用截图或被聊天软件严重压缩的图片替代。
